# OSINT — exposition des informations publiques

Synthèse anonymisée de deux exercices sur les informations qu’une organisation rend visibles en ligne. Le premier porte sur l’exposition des services web. Le second examine ce que les publications publiques révèlent sur les rôles et les technologies d’une organisation.

## Démarche

- Distinguer les observations vérifiables des hypothèses et indiquer les limites de l’analyse.
- Évaluer ce qu’une information publique peut révéler sur l’organisation et son infrastructure.
- Rédiger une restitution utile à la remédiation et anonymiser les personnes.

## Réduction de l’exposition

Tenir un inventaire des actifs publics, retirer les services obsolètes et limiter les détails opérationnels mis en ligne.
